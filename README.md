# FitOut Quotes (V2.9 – Phone App edition)

Quotation and invoice tool for FitOut Engineering & Construction Pte Ltd.
Works on computer and phone from the same link:

**https://fitoutengg-sg.github.io/quotes-app/**

This public edition has no internal Project Fee / Profit Sharing section.
The full version stays on the office computer only.

## Install on phone
- Android (Chrome): open the link → tap the orange **📲 Install App** button (or ⋮ menu → Install app).
- iPhone: open the link in Safari → tap Share (or ⋯ then Share) → **Add to Home Screen**.

## Updates
Only upload the update package Claude prepares (index.html + service-worker.js). Never upload the computer
version (FitOut_Quotation_System_V…html) here.

Quotes are saved on each device (in the browser), never on GitHub. Never upload quote files, passwords or bank details here.
